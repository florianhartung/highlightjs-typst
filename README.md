# Syntax Highlighting for [Typst](https://typst.app) via [Highlight.js](https://highlightjs.org)

## Development process

I've set up a small HTML site in [dev/index.html] with ~300 lines of Typst code
and a small script to watch the entire project and rebuild the JS and serve the
page on changes:

```sh
# run from project root:
npm run watch-and-serve-dev

# ...then open the displayed URL and then the dev directory
```
